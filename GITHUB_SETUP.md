# GitHub setup

1. Create a new GitHub repository named `coon-app`.
2. Upload/push the contents of this folder (not the parent ZIP folder).
3. Confirm that `.env`, `backend/data/`, `backend/uploads/`, and `node_modules/` are not tracked.
4. Keep this repository private while the project is still being developed if it contains anything you do not want public.
5. Deploy the backend from the `backend/` directory using `render.yaml`.
6. After the backend is deployed, set the frontend API base URL to the deployed backend URL.
